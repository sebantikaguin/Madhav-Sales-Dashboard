Madhav Sales Dashboard – Power BI

An interactive Power BI Sales Dashboard designed to analyze sales performance, profit, quantity, and customer trends. The dashboard provides clear visual insights into business performance through interactive charts, filters, and KPIs.

Key Features
Sales and profit analysis
State-wise and category-wise performance
Customer and payment-mode analysis
Monthly sales and profit trends
Interactive filters and visualizations
KPI-based business performance overview
Tools Used
Power BI
DAX
Data Cleaning & Transformation
Data Visualization

Purpose
This project demonstrates how Power BI can be used to transform sales data into meaningful and actionable business insights.
